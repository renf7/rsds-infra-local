# Security and local-only operation

Use only trusted PR code. The CLI requires a local Docker endpoint, creates a dedicated kind cluster/private kubeconfig and binds HTTP to loopback. It does not use AWS/prod credentials or change your global Kubernetes configuration. Never commit .local* directories or kubeconfig/state credentials. The Docker socket is used by the host CLI, not mounted into the application.

Scanners are configured per AGENTS.md and listed in SCANNER-VERSIONS.md. Go uses standard-library dependencies only; React ESLint and Java SpotBugs/Find Security Bugs do not apply to this repository. Configure a least-privilege SONAR_TOKEN Actions secret and public project rsds-infra-local in SonarCloud organization renf7. Fork PRs do not get the token. Missing Sonar configuration is a visible failure, not a green skipped scan. The workflow verifies default and PR modes before analysis and records real unit/integration coverage without changing the gate.

Native GitHub secret scanning and push protection were verified enabled on 30 October 2026. Dependabot vulnerability alerts and automatic security fixes were enabled and read back through the repository API on the same date. Weekly version-update configuration covers Go modules, scanner Python dependencies, and GitHub Actions; GitHub activates that configuration from the default branch after merge. These native features complement the per-PR CI scans. Required-check branch protection is a separate repository setting; do not infer it from YAML or these feature checks.

Tool downloads use official release endpoints and SHA256 sidecars; Go compiler image uses the supported 1.26 series. Application images are built locally from exact selected commits. No image is pushed, and production is never deployed. Control-plane image is pinned to kindest/node:v1.34.0 for the tested Docker Desktop compatibility; this is not a recommendation for a production Kubernetes upgrade policy.

Every local up also runs headless Chromium through pinned Python Playwright tooling inside Docker. The browser has no host mounts, Docker socket or credentials and runs as a non-root user with capabilities dropped. It accesses the local kind network only; the country service is mocked. Trivy scans the built browser image, CodeQL includes the Python test code, and Dependabot tracks its package pins and Docker base. Browser logs, JSON/JUnit, screenshots and traces are retained under each run's e2e directory; review page content before sharing artifacts if private flows are added later.
